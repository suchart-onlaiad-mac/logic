🔣 เงื่อนไขสัญลักษณ์

🌱 ชั้นเมล็ด · รู้แค่นี้ก็เข้าใจ

1 🧍 เรียงคนตามเงื่อนไข

แตะชื่อเรียงจากสูงที่สุดไปเตี้ยที่สุด แล้วดูว่าตรงทุกเงื่อนไขไหม 👇

2 ✏️ เขียนเป็นสัญลักษณ์

"ก้อย สูงกว่า แก้ม" เขียนเป็น ก้อย > แก้ม · ปากของเครื่องหมายอ้าไปทางตัวที่มากกว่า · ข้อความหลายข้อต่อกันเป็นโซ่ได้ เช่น ข้าว > ก้อย > แก้ม → สรุปได้ว่า ข้าว > แก้ม

🔑 โซ่ที่ชี้ทางเดียวกันตลอด สรุปตัวหัวกับตัวท้ายได้เสมอ
3 🟰 เครื่องหมาย > ≥ = ในโซ่เดียวกัน
ในโซ่มีตัวหัวกับตัวท้ายตัวอย่าง
> อย่างน้อย 1 ตัว>A > B = C → A > C
≥ กับ = (ไม่มี >)≥A ≥ B = C → A ≥ C
= ทุกตัว=A = B = C → A = C
< หรือ ≤ (ชี้ทางเดียวกัน)ใช้หลักเดียวกันA < B ≤ C → A < C
🔑 ≥ อ่านว่า "มากกว่าหรือเท่ากับ" · ≤ อ่านว่า "น้อยกว่าหรือเท่ากับ" ใช้หลักเดียวกัน (อย่างใดอย่างหนึ่ง) · ถ้ารู้แล้วว่า A > C ข้อสรุป A ≥ C ก็ถูกด้วย

⚠️ ถ้าโซ่ได้ A ≥ C แล้วข้อสรุปคือ A > C กับ A = C · สรุปแน่นอนไม่ได้ทั้งคู่ · ถ้าโจทย์มีตัวเลือก "ข้อสรุป 1 หรือ 2 ถูก" และโซ่ได้ ≥ ให้เลือกข้อนั้น · ในแอปนี้มี 4 ตัวเลือก จึงตอบ "ไม่ถูกเลย"
